# Ontario Parks Website 🌲

**IXD-Ontario-Parks** is a comprehensive camping and park reservation website designed for first-time campers and newcomers to Ontario. Built with **HTML, CSS, and JavaScript**, the website offers an intuitive digital experience for discovering, planning, and booking camping trips.

## Live Demo

Check out the live website [here](https://shokeent.github.io/IXD-Ontario-Parks/).

## Features

- Multi-page website: Homepage, Park Discovery, Park Details, Booking System, Gear Guide  
- Interactive Park Discovery: Filter parks by activities, amenities, and difficulty  
- Booking System: Date selection, campsite search, and real-time cost calculation  
- Gear Planning: Checklist and recommendations for camping essentials  
- Safety Alerts: Required acknowledgment for important park information  
- Responsive Design: Mobile-first approach for all device sizes  
- Accessibility: WCAG 2.1 compliant, keyboard navigation, screen reader support  

## Technologies Used

- **HTML5** – Semantic markup  
- **CSS3** – Flexbox, Grid, animations, responsive design  
- **JavaScript (ES6+)** – DOM manipulation, event handling, interactive forms  
- **Local Storage** – Data persistence for booking and gear checklist
